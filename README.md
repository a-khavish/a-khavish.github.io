# a-khavish.github.io

My portfolio. One HTML file, no build step, no dependencies, served from GitHub Pages.

The projects section pulls from the GitHub API on load and shows any public repo tagged
with the topic `portfolio`. The entries written into the markup are the fallback for when
JS is off or the API is unreachable.

Open `index.html` in a browser to work on it. Colours and type scale are custom properties
at the top of the stylesheet.
